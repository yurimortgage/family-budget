# Семейный бюджет — Telegram-бот + Mini App

Владелец — Юрий (общение на русском, кратко: сначала суть, потом детали). Пользуются он и жена.
Владелец не программист: всё, что нужно сделать руками, — пошагово, с точными названиями кнопок.

## Как устроено
- **Бот и данные** — Google Apps Script, привязанный к Google Таблице владельца
  (листы «Настройки», «Журнал», «Баланс», скрытый «График»).
  Исходник: `apps-script/budget-bot.gs`. Строки 1–18 (токен бота, адрес веб-приложения, кодовое слово)
  есть только у владельца в Apps Script — в репозитории там заглушки.
- **Mini App** — `index.html` на GitHub Pages (https://yurimortgage.github.io/family-budget/).
  Открывается в Telegram на весь экран, данные берёт POST-запросами к веб-приложению Apps Script
  (`API_URL` в index.html) → `doPost` → `apiResponse_` (`data`, `add`, `transfer`, `undo`).
- Вход в приложение: подпись Telegram (`initData`, проверка в `verifyInit_`)
  или личная ссылка `?u=…&k=…` из кнопки в чате (`appKey_` — HMAC от токена).
- Webhook Telegram принимается только с `?hook=hookKey_()` в адресе (адрес API публичный).
- Логика денег: налог % → постоянные фонды до месячной суммы → остаток по процентным фондам.
  Все фонды копятся, ничего не обнуляется автоматически. Слова «зп/зарплата/аванс/без налога/возврат»
  в доходе — налог не снимается (зарплата W-2).
- Публичный репозиторий: реальные фонды, суммы и имена семьи сюда не коммитить
  (в `DEFAULT_CFG` — обезличенный пример; настоящие значения — в листе «Настройки» таблицы).

## Как вносить изменения
- **Дизайн/экраны** — правка `index.html`, коммит в `main`; GitHub Pages обновляется сам за 1–2 минуты.
  Стиль: минималистичный, светлый, без ярких цветов, тонкие полоски; шрифт Montserrat.
- **Логика бота** — правка `apps-script/budget-bot.gs`, затем владелец вручную:
  Apps Script → Код.gs → щёлкнуть в начало строки 19 → Ctrl+Shift+End → вставить код с 19-й строки →
  Ctrl+S → «Начать развертывание → Управление развертываниями → ✏️ → Новая версия» → выполнить `setWebhook`.
  Файл для копирования удобно положить в его папку Google Drive «Семейный бюджет — Telegram-бот».
- Перед выдачей: `node apps-script/test.js` (имитация Apps Script и Telegram, данные обезличенные).
